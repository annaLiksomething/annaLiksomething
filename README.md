## Selected Projects

### [A Letter to the Inhabitant: Escaping the Virtual](https://liksomething.itch.io/a-letter-to-the-inhabitant)
*VR Installation + Physical Exhibition · Unity · C# · Meta Quest 3*  
My BA thesis in Studio Arts and Computer Science for Bard College. With this art installation I exlored how people perceive physical vs. virtual space. This interactive VR installation was exhibited alongside a physical representation of the same space. It is based on a domestic space belonging to a Russian household. Accompanied by original user research (n=16).

### [Our Last Walk - demo](https://ourlastwalk.vercel.app/)
*Puzzle Game · Unity · C# · 3D*  
An escape-room puzzle game where you play as a ghost of an old man - Rich Thorne and his loyal companion - border collie Angel. Solve puzzles using unique abilities of each character and learn more about life and death of Mr Rich. Built with a team of five as part of DH2650 Computer Game Design. Roles: developer, narrative designer, 2D artist.

### [Splash Boy: Ants Beware!](https://notneilbhatia.itch.io/splash-boy-ants-beware)
*Game Jam · Unreal Engine 5 · Blueprints · Top-Down Shooter*  
Made in 72 hours for Mini Jam 202 (theme: Power-up) in collaboration with [Neil Bhatia](https://github.com/notneilbhatia). A water-wielding baby defends his precious watermelon against never-ending ants. Roles: 3D artist, technical artist, developer.

### [Hierarchical Semantic WFC — Procedural Tile Map Generation](https://github.com/annaLiksomething/procedural-hswfc)
*Research Project · Python*  
Implementation of a Hierarchical Semantic Wave Function Collapse algorithm for procedural tile map generation done in collaboration with [Natalie Eriksson](https://github.com/nataliie01). Tile assets hand-drawn and inspired by *Carcassonne*. A final project for DH2323 Computer Graphics and Interaction. Includes a [devblog](https://wooded-prose-a7b.notion.site/13-tiles-are-born-359d86066a7480609674e8afe63e7083) and full [project report](https://github.com/annaLiksomething/procedural-hswfc/blob/main/DH2323ProjectReport.pdf).
